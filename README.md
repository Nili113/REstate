Kenisha Real Estate Pvt. Ltd. - Web Portal

Overview:
Official corporate website for Kenisha Real Estate Pvt. Ltd., based in Arjundhara-06, Jhapa, Nepal.
Founder and Managing Director: Miss Kenisha (Ranjita Dulal).

Requirements:
Node.js version 18 or newer
pnpm package manager (recommended) or npm

Getting Started:
1. Install dependencies:
pnpm install

2. Run local development server:
pnpm run dev
Open your browser at: http://localhost:3000

3. Build production bundle:
pnpm run build

4. Preview production build locally:
pnpm run preview
